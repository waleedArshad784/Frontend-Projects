# 👤 Random User Generator

A simple and interactive web application built with **HTML**, **Tailwind CSS**, and **JavaScript** that fetches random user information from the **Random User API** and displays it dynamically on the webpage.

---

##  About the Project

The **Random User Generator** allows users to generate a new random profile with a single button click. The application retrieves real-time data from an external API and updates the user interface without refreshing the page.

This project was built to practice **modern JavaScript concepts**, **API integration**, and **DOM manipulation**.

---

##  Features

* Generate a random user with one click
* Display user's profile picture
* Display full name
* Display email address
* Display country
* Display phone number
* Fetch real-time data using the Fetch API
* Dynamic UI updates without page reload

##  How to Run the Project

1. Clone the repository

```bash
git clone https://github.com/your-username/random-user-generator.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

4. Click the **Generate User** button to load a random user.
