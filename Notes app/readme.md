# 📝 Notes App

A modern and responsive **Notes App** built using **HTML, Tailwind CSS, and JavaScript**. This project allows users to create, edit, delete, and store notes permanently using the browser's Local Storage.

---

## 🚀 Live Features

- ✅ Add New Notes
- ✅ Edit Existing Notes
- ✅ Delete Notes
- ✅ Save Notes in Local Storage
- ✅ Responsive Card Layout
- ✅ Dynamic Date & Time
- ✅ Beautiful UI with Tailwind CSS
- ✅ Real-Time DOM Updates

---

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS
- JavaScript (ES6+)
- Local Storage API

## 🎯 Features

### ➕ Add Note

Create a new note by entering a title and description.

---

### ✏️ Edit Note

Update any existing note without creating a duplicate.

---

### 🗑 Delete Note

Delete unwanted notes instantly.

---

### 💾 Local Storage

All notes are stored inside the browser using Local Storage, so refreshing the page does not remove your notes.

---

### 📅 Date Tracking

Each note stores the date when it was created.
