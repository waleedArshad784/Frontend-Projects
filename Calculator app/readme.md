# Modern Dark-Mode Calculator App

A sleek, responsive calculator web application built with HTML, CSS, and JavaScript. Featuring a dark-themed UI with subtle glow effects and modern button stylings.


---

##  Features

- **Modern UI/UX**: Clean dark theme with smooth circular button designs and orange emphasis accents.
- **Full Standard Functionality**:
  - Basic arithmetic operations: Addition (`+`), Subtraction (`-`), Multiplication (`*`), and Division (`/`).
  - Clear (`AC`) and Delete (`DEL`) functions for easy input editing.
  - Percentage calculations (`%`) and standard decimal points (`.`).
  - Convenient double-zero button (`00`).
- **Responsive Layout**: Designed to look sharp across various screen sizes.

---

## Tech Stack

- **HTML5**: Semantic markup for application structure.
- **CSS3**: Custom styles, flexbox/grid layout, dark-mode aesthetics, and CSS variables.
- **JavaScript (ES6+)**: Logic handling for calculations and UI interactions.
