 Dynamic To-Do List App

A simple and interactive Dynamic To-Do List built with HTML, CSS, and Vanilla JavaScript. This project demonstrates how to dynamically create, style, and remove HTML elements using JavaScript without writing static HTML for each task.


✨ Features
➕ Add new tasks dynamically.
🗑️ Delete tasks with a single click.
🎨 Dynamically apply CSS classes using classList.
⚡ Real-time DOM updates without refreshing the page.
📱 Clean and responsive user interface.
✅ Built using pure JavaScript (No frameworks).

🎯 How It Works
Enter a task in the input field.
Click the Add button.
JavaScript creates a new task element dynamically.
The task is automatically styled using CSS classes through classList.
Click Delete Task to remove the task instantly.
